# 🖥 PC Full Control

Управление компьютером с телефона: **Telegram-бот** (работает из любой точки, без проброса портов)
и **веб-панель** для телефона (в домашней сети). Уведомления о важных событиях приходят в Telegram.

Все данные хранятся **только локально** в SQLite (`data/pcontrol.db`): журнал, задачи, метрики, сеансы.
Никаких облачных баз (Firebase и т.п.) не используется — наружу идут только запросы к Telegram API.

Основная платформа — **Windows 10/11**. Большинство функций также работает в Linux и macOS.

## Быстрый старт (Windows)

1. **Установите Python 3.10+** — с [python.org](https://www.python.org/downloads/) (отметьте *Add python.exe to PATH*) или командой `winget install Python.Python.3.12`.
2. **Скачайте проект** (`git clone` или ZIP) в постоянную папку, например `C:\PCControl`.
3. **Создайте Telegram-бота**: напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
4. Нажмите правой кнопкой на **`install_windows.bat`** → **Запуск от имени администратора**. Скрипт:
   - создаст окружение `.venv` и установит зависимости;
   - спросит токен бота и запишет его в `config.yaml`;
   - откроет порт веб-панели в брандмауэре (только для частных сетей);
   - добавит автозапуск при входе в Windows (Планировщик заданий, с правами администратора, без окна);
   - покажет **пароль веб-панели** и **код привязки** Telegram.
5. **Привяжите телефон**: откройте своего бота в Telegram и отправьте `/pair КОД` (код из окна установки или из `data\pcontrol.log`).
   Готово — нажмите `/start`, появится меню с кнопками.

> Права администратора нужны для Windows Update, завершения некоторых процессов и обновления программ через winget.
> Агент запускается **в сеансе пользователя**, поэтому работают скриншоты, звук и сообщения на экран.

Ручной запуск в окне консоли (для проверки): `start_console.bat`.
Удаление автозапуска: `uninstall_windows.bat` (от администратора).

## Linux

```bash
git clone <репозиторий> ~/pcfullcontrol && cd ~/pcfullcontrol
./scripts/install_linux.sh
```

Агент ставится как пользовательская служба systemd. Для скриншотов нужен графический сеанс,
для громкости — `pactl` (PulseAudio/PipeWire), для медиа — `playerctl`, для буфера — `xclip`.
Обновление пакетов требует root: см. подсказку про `sudoers` в конце установки.

## Telegram-бот

Кнопки меню: **Статус · Скриншот · Питание · Медиа · Процессы · Обновления · Файлы · Планировщик · Ещё · Журнал**.

Команды:

| Команда | Действие |
|---|---|
| `/status` | состояние ПК |
| `/screen` | скриншот |
| `/shutdown [мин]`, `/reboot [мин]`, `/cancel` | выключить / перезагрузить / отменить |
| `/sleep`, `/hibernate`, `/lock`, `/logoff`, `/monitoroff` | сон, гибернация, блокировка, выход, монитор |
| `/vol 40`, `/mute`, `/media` | громкость и медиа |
| `/ps [имя]`, `/kill chrome` | процессы |
| `/updates` | обновление ПО |
| `/files [путь]`, `/get путь` | файлы; **отправьте файл боту** — он сохранится в `Загрузки\PCControl` (подпись «сюда» — в открытую в `/files` папку) |
| `/at 23:30 shutdown` | разовая задача на время |
| `/in 1h30m reboot` | задача через интервал (`30`, `45m`, `2h`, `1h30m`) |
| `/daily 08:00 будни notify Подъём!` | по расписанию (`будни`, `выходные`, `пн-пт`, `сб,вс`) |
| `/tasks`, `/deltask 3`, `/actions` | список задач, удаление, названия действий |
| `/msg текст`, `/say текст` | сообщение на экран / озвучить |
| `/open ссылка`, `/run программа` | открыть ссылку / запустить программу |
| `/clip [текст]` | прочитать / записать буфер обмена ПК |
| `/cmd команда` | выполнить команду (если `allow_shell: true`) |
| `/ip`, `/webcam`, `/log` | IP-адреса, веб-камера, журнал |
| `/notify` | вкл/выкл уведомления (критические приходят всегда) |
| `/web` | адрес веб-панели, новый пароль, завершить сеансы |
| `/users`, `/unpair ID` | привязанные пользователи |
| `/myid` | узнать свой Telegram ID |

Опасные действия (выключение, перезагрузка, завершение процессов, обновление всего) требуют подтверждения кнопкой.
**Команды, отправленные боту, пока ПК был выключен, не выполняются** после включения — чтобы
старый «/shutdown» не выключил компьютер сразу после загрузки.

## Веб-панель

Откройте на телефоне `http://IP-компьютера:8765` (адрес приходит в Telegram при запуске, а также по `/web` и `/ip`).
Через меню браузера «Добавить на главный экран» панель открывается как приложение.

Вкладки: **Главная** (показатели, график, питание, звук, скриншот) · **Процессы** · **Файлы** · **Задачи** · **Ещё**
(обновления, быстрые действия, терминал, журнал, настройки и смена пароля).

**Доступ не из дома.** Telegram-бот работает откуда угодно. Для веб-панели вне домашней сети используйте VPN
[Tailscale](https://tailscale.com/) (бесплатно: установите на ПК и телефон, открывайте `http://<tailscale-IP>:8765`).
**Не пробрасывайте порт веб-панели в интернет** — она работает по HTTP без шифрования.

## Настройки (`config.yaml`)

Создаётся из `config.example.yaml` при первом запуске. Главное:

```yaml
telegram:
  token: "123456:ABC..."        # токен от @BotFather
  allowed_user_ids: []          # можно указать ID вместо /pair
  confirm_dangerous: true
web:
  host: 0.0.0.0                 # 127.0.0.1 — только с этого ПК
  port: 8765
security:
  allow_shell: false            # терминал /cmd
files:
  allowed_roots: []             # например ["C:\\Users\\me\\Documents"] — ограничить файловый менеджер
apps:                           # свои кнопки в «Ещё → Мои программы»
  Steam: "C:\\Program Files (x86)\\Steam\\steam.exe"
monitor:
  cpu_percent: 90               # пороги тревог
  disk_free_percent: 10
  watch_processes: ["steam.exe"]
updates:
  daily_check_time: "12:00"     # ежедневная проверка обновлений
```

После изменения настроек перезапустите агент (кнопка «♻️ Перезапуск агента» в боте или веб-панели).

Пароль веб-панели: `python run.py --set-password`, в веб-панели («Ещё → Настройки») или в Telegram (`/web` → «Новый пароль»).
Код привязки Telegram: `python run.py --pair-code` или в веб-панели («Ещё → Настройки»).

## Безопасность

- Ботом управляют только привязанные пользователи; чужие попытки приходят вам уведомлением.
- Код привязки одноразовый; 5 неверных попыток — блокировка.
- Пароль веб-панели хранится в виде хеша PBKDF2; после 5 неверных вводов IP блокируется на 15 минут, вы получите уведомление.
- Терминал выключен по умолчанию. Файловый менеджер можно ограничить папками (`allowed_roots`), удаление папок запрещено.
- Все команды пишутся в локальный журнал (`/log`, вкладка «Ещё → Журнал»).
- Токен бота хранится в `config.yaml` — этот файл исключён из git.

## Частые вопросы

**Бот не отвечает.** Проверьте токен в `config.yaml` и лог `data\pcontrol.log`. Ошибка 409 — бот запущен
где-то ещё (два агента с одним токеном). В некоторых сетях Telegram заблокирован — укажите `telegram.proxy`.

**Скриншот чёрный или ошибка.** Агент должен работать в сеансе пользователя (так его и ставит установщик), а не как служба Windows.

**Нет температуры CPU в Windows.** Windows отдаёт её не на всех платах. Видеокарты NVIDIA показываются через `nvidia-smi`.

**Сон вместо этого уходит в гибернацию.** Это поведение Windows при включённой гибернации: `powercfg /h off` отключает её.

**winget не найден.** Установите «Установщик приложений» (App Installer) из Microsoft Store.
