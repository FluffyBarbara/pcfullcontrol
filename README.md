# 🖥📱 PC Full Control

Программа для Windows, которая позволяет **управлять компьютером с телефона**:

- **📱 Приложение на телефоне** (Android и iPhone) — работает по домашнему Wi‑Fi, привязка по QR-коду;
- **✈️ Telegram-бот** — работает из любой точки мира, плюс уведомления о важных событиях.

Программа на ПК устанавливается как обычное приложение (`.exe`), живёт в трее и запускается вместе с Windows.
Написано на **HTML, CSS и JavaScript** (Electron). Все данные хранятся **только на компьютере** в локальной базе SQLite.

## Установка

1. **На компьютере** запустите `PCFullControl-Setup.exe`. Если Windows покажет «Неизвестный издатель» —
   «Подробнее» → «Выполнить в любом случае». Разрешите права администратора (нужны для выключения ПК и обновлений).
2. Откроется программа → раздел **«Телефон»**.

**Приложение на телефоне (по Wi‑Fi):**
- **Android:** установите `PCControl-Android.apk` (разрешите установку из неизвестных источников) → «Сканировать QR-код» → наведите на QR-код в программе на ПК.
- **iPhone:** наведите обычную камеру на QR-код → откроется Safari → кнопка «Поделиться» → **«На экран Домой»**.
  Apple не разрешает ставить приложения мимо App Store без платного аккаунта разработчика, поэтому на iPhone
  это веб-приложение — со своим значком, на весь экран, как обычное приложение.
- Телефон и компьютер должны быть в одной сети Wi‑Fi (вне дома — Telegram-бот или VPN вроде Tailscale).

**Telegram-бот (из любой точки):**
вкладка «Telegram-бот» → создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) → вставьте токен →
отсканируйте QR-код камерой телефона → в боте нажмите «Запустить».

Обновления: программа сама проверяет новые версии; установить можно в «О программе» или из Telegram.
После обновления показывается окно **«Что нового»**.

## Что умеет

| Раздел | Возможности |
|---|---|
| ⚡ **Питание** | выключить, перезагрузить (сразу или через N минут), отменить, сон, гибернация, блокировка, выход из системы, выключить монитор |
| 📊 **Состояние** | процессор, память, диски, температура, видеокарта, батарея, IP, время работы; графики в приложении |
| 🔄 **Обновление ПО** | winget, Chocolatey, Scoop, **Windows Update** (поиск и установка), обновление самого PC Full Control |
| 🧩 **Процессы** | список (по CPU/памяти), поиск, завершение по PID или имени |
| 📸 **Экран** | скриншот (все мониторы или один, сжатый или файлом), фото с веб-камеры |
| 🔊 **Звук** | громкость точно (0–100%) и шагами, без звука, пауза/следующий/предыдущий трек |
| 📁 **Файлы** | обзор дисков и папок, скачивание файлов на телефон, отправка файлов с телефона на ПК |
| ⏰ **Планировщик** | «выключи в 23:30», «через 45 минут», «по будням в 08:00 напомни…» |
| 🛠 **Разное** | сообщение на экран ПК, озвучка текста, открыть ссылку, запустить программу, буфер обмена, очистка корзины, свои кнопки программ |
| 💻 **Команды** | выполнение команд PowerShell (по умолчанию **выключено**, включается в настройках) |

### Уведомления в Telegram

- компьютер включён (и сколько был выключен), ушёл в сон / проснулся;
- вход в систему и разблокировка компьютера;
- высокая загрузка CPU или памяти (с самыми «тяжёлыми» процессами), мало места на диске, перегрев;
- низкий заряд батареи, подключение/отключение зарядки;
- смена сети/IP, запуск и закрытие выбранных программ;
- кто-то посторонний пытается писать вашему боту;
- результаты обновлений и задач планировщика.

Пороги и типы уведомлений настраиваются во вкладке **«Настройки»**. Быстро выключить уведомления — `/notify`
или галочка в меню значка в трее (критические тревоги приходят всегда).

## Команды бота

Кроме кнопок, можно писать команды:

| Команда | Действие |
|---|---|
| `/status` | состояние ПК |
| `/screen` | скриншот |
| `/shutdown [мин]`, `/reboot [мин]`, `/cancel` | выключить / перезагрузить / отменить |
| `/sleep`, `/hibernate`, `/lock`, `/logoff`, `/monitoroff` | сон, гибернация, блокировка, выход, монитор |
| `/vol 40`, `/mute`, `/media` | звук |
| `/ps [имя]`, `/kill chrome` | процессы |
| `/updates` | обновление ПО |
| `/files [путь]`, `/get путь` | файлы; **просто отправьте файл боту** — он сохранится в `Загрузки\PCControl` |
| `/at 23:30 shutdown` | разовая задача на время |
| `/in 1h30m reboot` | задача через интервал (`30`, `45m`, `2h`, `1h30m`) |
| `/daily 08:00 будни notify Подъём!` | по расписанию (`будни`, `выходные`, `пн-пт`, `сб,вс`) |
| `/tasks`, `/deltask 3`, `/actions` | список задач, удаление, названия действий |
| `/msg текст`, `/say текст` | сообщение на экран / озвучить |
| `/open ссылка`, `/run программа` | открыть ссылку / запустить программу |
| `/clip [текст]` | прочитать / записать буфер обмена ПК |
| `/cmd команда` | выполнить команду (если разрешено) |
| `/ip`, `/webcam`, `/log`, `/notify`, `/users`, `/myid` | IP, веб-камера, журнал, уведомления, телефоны, ваш ID |

## Безопасность

- Ботом управляют только привязанные телефоны. Привязка — одноразовым кодом из QR (после привязки код меняется),
  5 неверных попыток — блокировка. Отвязать телефон можно в приложении.
- Посторонние, написавшие боту, получают отказ, а вам приходит уведомление.
- Выключение, перезагрузка, завершение процессов, «обновить всё» требуют подтверждения кнопкой.
- **Команды, отправленные боту, пока ПК был выключен, не выполняются** после включения
  (старый `/shutdown` не выключит компьютер сразу после загрузки).
- Выполнение произвольных команд выключено по умолчанию; файловый менеджер можно ограничить папками.
- Все команды пишутся в локальный журнал (вкладка «Журнал»).
- Токен бота хранится только в локальной базе на этом компьютере.
- Приложение на телефоне получает доступ только после привязки одноразовым 6-значным кодом с экрана ПК
  (код живёт 10 минут, 5 неверных попыток — блокировка). Любой телефон можно отвязать в разделе «Телефон».
- Связь телефона с ПК идёт по домашней сети без шифрования — не открывайте порт 8765 в интернет.

Где лежат данные: `%APPDATA%\PC Full Control\pcontrol.sqlite` (кнопка «Папка с данными» в настройках).

## Для разработчика

```bash
npm install        # зависимости
npm start          # запуск приложения
npm test           # тесты (node:test)
npm run dist       # сборка установщика Windows (запускать на Windows)
```

Установщик собирается автоматически в GitHub Actions (`.github/workflows/build.yml`) на Windows.
Каждый push в `main` публикует релиз `v<version из package.json>` с `PCFullControl-Setup.exe`.
Чтобы выпустить новую версию, поднимите `version` в `package.json` — после этого установленные приложения
смогут обновиться командой «🤖 Обновить PC Full Control» в боте.

### Структура

```
src/main/                  главный процесс (Node.js)
  main.js                  окно, трей, автозапуск, связь с интерфейсом
  context.js               общий контекст приложения
  db.js                    локальная база SQLite (sql.js / WebAssembly)
  config.js                настройки по умолчанию
  bot.js                   Telegram-бот: меню, кнопки, команды, файлы, привязка
  telegram-api.js          клиент Telegram Bot API (fetch)
  notifier.js              очередь уведомлений
  monitor.js               мониторинг и тревоги
  scheduler.js             планировщик задач
  actions.js               единый список действий (бот, окно, планировщик)
  jobs.js                  фоновые задания (обновления)
  app-updater.js           обновление приложения из GitHub Releases
  lan-server.js            сервер для приложения на телефоне (Wi-Fi, привязка по коду)
  system/                  питание, процессы, звук, экран, обновления, файлы, разное
src/renderer/              интерфейс программы на ПК (HTML/CSS/JS)
src/mobile/                приложение на телефоне (раздаётся программой на ПК)
src/shared/                иконки и история изменений (общие для ПК и телефона)
android-app/               Android-приложение (Capacitor): сканер QR и список компьютеров
build/                     иконка и шаг установщика (автозапуск через Планировщик заданий)
tests/                     тесты
```

## Частые вопросы

**Бот не отвечает.** Посмотрите статус внизу слева в приложении. «Ошибка 409» — этот же бот запущен на другом
компьютере. Если Telegram заблокирован в вашей сети, приложению нужен доступ к `api.telegram.org` (VPN).

**Нет температуры CPU.** Windows отдаёт её не на всех материнских платах.

**«Сон» уходит в гибернацию.** Так ведёт себя Windows при включённой гибернации: `powercfg /h off` в командной строке
администратора отключает её.

**winget не найден.** Установите «Установщик приложений» (App Installer) из Microsoft Store.
