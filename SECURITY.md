# Безопасность PC Full Control

## Как сообщить об уязвимости

**Не публикуйте уязвимость в открытых Issues.** Сообщите приватно:

- через GitHub: вкладка **Security → Report a vulnerability** (приватное сообщение владельцу репозитория);
- или в Telegram: [@fluffybarbara](https://t.me/fluffybarbara).

Опишите, что можно сделать, при каких условиях и как воспроизвести. Мы подтвердим получение в течение 3 дней,
исправление серьёзных проблем выходит обычно в течение 7 дней. Тихие исправления (x.y.1…) ставятся
у пользователей автоматически, но не раньше чем через 6 часов после выхода релиза.

## Поддерживаемые версии

Исправления выходят только для последней версии. Программа обновляется сама.

## Модель угроз

Программа управляет компьютером с телефона по **домашней сети Wi-Fi** и через **Telegram-бота**.
Мы защищаемся от:

- посторонних в той же сети (гости, соседи, устройства умного дома) — подслушивание и подмена трафика;
- подключений через VPN, виртуальные адаптеры, открытые сети Wi-Fi и из интернета;
- подбора кодов привязки, повторной отправки перехваченных запросов, DNS rebinding;
- кражи файла базы данных (секреты зашифрованы средствами Windows);
- вредоносной программы без прав администратора (подмена помощников и системных программ через PATH);
- украденного разблокированного телефона — по желанию владельца код-пароль на вход в приложение.

Вне модели угроз: вредоносная программа **с правами администратора** на этом ПК, взлом аккаунта Telegram
владельца (включите облачный пароль Telegram), взлом аккаунта GitHub владельца.

## Как устроена защита

| Область | Механизм |
|---|---|
| Привязка телефона | Только пока на ПК открыт раздел «Телефон»; QR-код несёт секрет во фрагменте адреса (в сеть не уходит); ввод кода вручную — обмен ключами X25519; лимиты попыток, смена кода и тревога при подборе |
| Канал телефон ↔ ПК | Подпись каждого запроса HMAC-SHA256 (метод, адрес, время, одноразовое число), защита от повтора; тела запросов и ответов шифруются ChaCha20 + HMAC; флаг шифрования входит в подпись |
| Сеть | Только устройства из той же домашней подсети через физический адаптер; VPN, виртуальные адаптеры, открытый Wi-Fi и «белые» адреса отсекаются; брандмауэр — только локальная подсеть; проверка заголовка Host |
| Файлы | По умолчанию — папка пользователя без AppData, ключей и скрытых файлов; данные программы закрыты всегда (с тревогой); запись — только в папку загрузок; исполняемые файлы не принимаются |
| Секреты | Токен бота — DPAPI (Electron safeStorage); токены телефонов и виджетов — только хэши; код привязки Telegram — только в памяти; `secure_delete` в базе |
| Процессы | Песочница Chromium во всех окнах; помощники — в Program Files; системные программы — по полному пути |
| Обновления | Проверка SHA-512; тихие исправления — не раньше 6 часов после выхода; бинарники сторонних инструментов в сборке — по SHA-256 и подписи издателя; GitHub Actions — по SHA коммитов |
| Криптография | Своя реализация SHA-256/HMAC/ChaCha20/X25519 (страница телефона открыта по http:// — там нет WebCrypto); проверяется тест-векторами RFC 4231 / 8439 / 7748 и случайными сверками с Node на каждой сборке |

## Известные ограничения

- Установщик и APK пока без коммерческой цифровой подписи — сверяйте SHA-256 из описания релиза.
- Программа работает с правами администратора (нужны для выключения, обновлений Windows, удаления программ).
  Разделение на обычный процесс и узкий привилегированный помощник — в планах.
- Страницы приложения телефона загружаются с ПК по http://: активный посредник в вашей сети при самой первой
  загрузке может подменить страницу. Не пускайте недоверенные устройства в домашний Wi-Fi.
- Ссылки для «Команд» iPhone содержат ключ виджета в адресе: «Команды» не умеют подписывать запросы.
