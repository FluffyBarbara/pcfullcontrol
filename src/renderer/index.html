Телефон

Два способа управлять компьютером с телефона — можно использовать оба.

Приложение по Wi-Fi

1

Установите приложение

AndroidСкачайте PCControl-Android.apk и установите.
iPhoneОтсканируйте QR камерой → Safari → «Поделиться» → «На экран Домой».
2

Отсканируйте QR-код

В приложении нажмите «Сканировать QR-код» (на iPhone — просто камерой). Или введите код вручную.

3

Готово

Телефон и компьютер должны быть в одной сети Wi-Fi. Вне дома пользуйтесь Telegram-ботом.

Привяжите Telegram

Включение компьютера с телефона

        
Выключенный компьютер можно включить кнопкой «Включить» в Android-приложении — оно отправляет в домашнюю сеть «волшебный пакет» (Wake-on-LAN).
          Нужно: подключение по кабелю, пункт «Wake on LAN» / «Power On By PCI-E» в BIOS и настройка Windows кнопкой ниже.
